# Ionic component reference

This catalog gives each shared Ionic component a focused page: where it fits,
how to compose it, and the interaction and accessibility rules that apply across
Sneat apps. The broader patterns stay in the [frontend UX standards](../README.md);
component pages link back to those guides instead of copying them.

## Components

- [`ion-item-divider`](./ion-item-divider.md) — semantic headings between item
  groups, neutral styling, optional counts, and accessible collapse controls.
  Also the required header row of every `ion-card`
  (`color="light"`, see [`cards.md`](../cards.md#card-headers)).
